Abstract

This project investigates how historical search performance and engagement metrics can be used to identify content pages that deserve attention from SEO teams. Using the FlyRank ML Internship Warehouse dataset, a supervised machine learning workflow was developed to estimate a content opportunity score for each page. Historical Google Search Console and Google Analytics signals were transformed into predictive features and modeled using a Random Forest Regressor. The resulting ranking provides decision support for prioritizing content updates while following responsible machine learning practices and avoiding data leakage.

Introduction

Large websites often contain thousands of pages, making manual content review impractical. Search teams need an efficient method for identifying which pages should be refreshed first.

The objective of this project is to build a repeatable machine learning workflow that ranks content pages according to their optimization opportunity using historical search intelligence data.

This project is intended as decision support rather than proof of Google's ranking algorithms or causal relationships.

Ranked Recommendations

The trained model was used to rank pages according to their predicted opportunity score. Pages with the highest scores should receive priority during content optimization.

  1. Refresh pages with declining organic traffic.
  2. Improve titles and meta descriptions for pages with high impressions but low CTR.
  3. Update outdated content using current information.
  4. Improve internal linking for valuable content.
  5. Monitor pages with strong performance and protect them from unnecessary changes.

Limitations

  • This project identifies associations rather than causal relationships.
  • The model depends on historical search performance.
  • Results are intended for decision support.
  • No private client information is included.
  • Future Google ranking behavior cannot be predicted with certainty.
