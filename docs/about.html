Experience

💼 Machine Learning Intern — FlyRank

Built an end-to-end machine learning project using FlyRank's anonymized, multi-client Content Refresh dataset — from a transparent baseline rule through a validated classification model to this deployed research site.

  • ✔ Queried and explored search intelligence data with pandas and DuckDB.
  • ✔ Built and verified a transparent baseline rule against real signal checks.
  • ✔ Caught and corrected a target-leakage mistake before it reached the final model.
  • ✔ Trained a Random Forest classifier on 23 leak-checked features.
  • ✔ Validated honestly with a client-grouped split, reporting the resulting generalization gap.
  • ✔ Turned the model's output into a ranked, reason-coded action queue.
  • ✔ Deployed the full write-up as a public, multi-page research site with reproducible notebooks.

Project Highlights

📊 Dataset

30,000 anonymized content pages across 32 client portfolios, from FlyRank's Content Refresh release.

🧠 Model

Random Forest classifier predicting declining search visibility, ranked by predicted probability.

⚡ Technologies

Python, pandas, NumPy, scikit-learn, DuckDB, HTML, CSS, and JavaScript.

📈 Outcome

F1 0.836 vs. a 0.352 baseline on the same split — and an honestly-reported ROC-AUC drop to 0.635 on unseen clients.
