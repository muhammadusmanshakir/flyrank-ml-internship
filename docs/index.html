Research Overview

This capstone project investigates how machine learning can identify high-value content opportunities using FlyRank's Search Intelligence Warehouse. A Random Forest Regression model was trained to predict search performance from content-level features and generate actionable recommendations for SEO optimization.

Model Results

Baseline MAE: 41.37

Random Forest MAE: 0.224

Random Forest R²: 0.997

Ranked Recommendations

  • Prioritize content with the highest predicted opportunity scores.
  • Refresh declining pages before creating new content.
  • Monitor pages with low engagement despite high visibility.
  • Use feature importance to guide future content optimization.
