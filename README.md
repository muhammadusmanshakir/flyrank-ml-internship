# 📖 Project Overview

This project was developed as the capstone project for the **FlyRank Machine Learning Internship**.

The objective is to identify **high-value content opportunities** using Machine Learning and Search Intelligence data.

Instead of manually reviewing thousands of webpages, the trained model predicts which pages have the greatest optimization potential, allowing SEO teams to prioritize their efforts efficiently.

The complete workflow includes:

- Data Exploration
- Data Cleaning
- Feature Engineering
- Machine Learning
- Model Evaluation
- Result Visualization
- Professional Portfolio Website

---

# 🎯 Objectives

The project aims to:

- Build a complete Machine Learning pipeline.
- Analyze large-scale Search Intelligence data.
- Engineer meaningful predictive features.
- Train a Random Forest Regression model.
- Compare performance with a baseline model.
- Generate actionable SEO recommendations.
- Present results through a professional website.

# 📊 Results

The trained Random Forest Regression model significantly outperformed the baseline model.

| Metric | Result |
|---------|---------:|
| Baseline MAE | **41.37** |
| Random Forest MAE | **0.224** |
| R² Score | **0.997** |
| Dataset Size | **~79 Million Search Records** |

### Key Findings

- Excellent predictive performance
- Significant reduction in prediction error
- High-quality feature importance analysis
- Actionable SEO recommendations
- Explainable Machine Learning workflow
