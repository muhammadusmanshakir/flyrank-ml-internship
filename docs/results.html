Feature importance & errors

Figure 3. The model is driven mostly by sustained visibility and average search position, not by simple content attributes like word count.

Of 6,000 test rows (random split), the model produced 1,412 misclassifications (23.5% error rate) — 1,055 false positives and 357 false negatives. The model over-flags more than it under-flags, which fits its intended use: a false positive costs an editor a look, a false negative costs a missed cycle.

Key findings

🎯 Model beats baseline

F1 improves from 0.352 to 0.836 on the same test split — a large, real gap.

⚠️ Honest gap on new clients

ROC-AUC drops from 0.795 to 0.635 when validated on clients the model has never seen.

🔍 Explainable

Feature importance shows the model leans on sustained visibility signals, not simple content length.

🚀 Decision support

The output prioritizes review; it does not automate publishing decisions.
