What this project is

A large content library decays unevenly. Some pages keep earning search visibility for years; others quietly lose ground for months before anyone notices — and no editorial team can manually re-check every page on a fixed schedule.

This project builds a transparent baseline rule, then a validated machine learning model, to rank pages by how likely they are to keep declining — turning that ranking into a reason-coded action queue an editor can actually work from. The most important result isn't the model's best score; it's what happened when that score was tested honestly.
